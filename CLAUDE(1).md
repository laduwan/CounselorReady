# CLAUDE.md

## Code Fix Rules
- ONLY fix what is broken. Do not change colors, fonts, components, emojis, sizing, or layout unless explicitly asked.
- Work with what's already there — never swap out or redesign elements to "make it work" without express consent.
- Do not refactor, rename, or reorganize files or components unless specifically requested.
- If a fix requires changing a visual element, ask first before proceeding.
