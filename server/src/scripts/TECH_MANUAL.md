
### 2026-09-01 — Course-level `subtitle` is documented in §1 but undeclared on CourseSchema
`CLAUDE_COURSE_STRUCTURE.md` §1 lists `subtitle` in the canonical COURSE shape, but `CourseSchema` never declares it at course level — the `title`/`subtitle` at `InteractiveCourse.js` lines 105/111 belong to `ContentBlockSchema`, which is easy to misread when grepping. Because the course schema is `strict: true`, a course-level `subtitle` is silently dropped by the `doc.save()` path §0 mandates. Courses that appear to have one (e.g. `cultural-competence-ethics-risk-reduction-cr601`) were raw-inserted through the driver, which bypassed strict mode — the same divergence the #908 entry describes from the read side. Same check run across the new CR-439 / CR-CULTR-603 seeds also caught `ceuEligible` (already flagged in §1) and `category` (undeclared; `ceCategory` and `contentArea` are the declared fields). Left unresolved pending Ke: either `subtitle` gets declared on the schema, or §1 should stop listing it. Worth running the same audit over any seed authored from the older `.docx` reference.
