🔧 Configuration Guide

Add these environment variables to your Render service:

# LTI Configuration
LTI_CONSUMER_KEY=your-consumer-key
LTI_CONSUMER_SECRET=your-secret-key

# xAPI / LRS Configuration
XAPI_ENDPOINT=https://your-lrs.com/xapi
XAPI_USERNAME=your-lrs-username
XAPI_PASSWORD=your-lrs-password

# CE Broker Configuration
CE_BROKER_API_KEY=your-api-key
CE_BROKER_PROVIDER_ID=your-provider-id
CE_BROKER_SANDBOX=false

# Base URLs
BASE_URL=https://counselorready-2.onrender.com
FRONTEND_URL=https://counselorready.com
