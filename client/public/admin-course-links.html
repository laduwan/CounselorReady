Enrollment Wiring Fix — Backend Patches Required

🔴 Issue 1 — Admin stats miss interactivecourses enrollments

In routes/admin.js, the GET /stats handler queries Course but not InteractiveCourse or UserCourseProgress.

Fix — add to stats handler:

const [totalEnrollments, completions] = await Promise.all([
  UserCourseProgress.countDocuments(),
  UserCourseProgress.countDocuments({ status: 'completed' })
]);
// Include in response: totalEnrollments, completions

🔴 Issue 2 — Assessment 404 on inline isExam blocks

In routes/courseRoutes.js, POST /:id/assessment only checks course.assessment top-level field — inline isExam: true quiz blocks are ignored.

Fix — normalize in handler:

// After fetching course, normalize exam:
const examBlock = course.assessment || 
  course.sections?.flatMap(s => s.contentBlocks)
    .find(b => b.type === 'quiz' && b.isExam);
if (!examBlock) return res.status(404).json({error:'No assessment'});

🟡 Issue 3 — Activity log not fired on enrollment

POST /:id/enroll in courseRoutes.js creates a UserCourseProgress record but does not write to the admin activity log.

Fix — add after successful enroll:

await Activity.create({
  type: 'enrollment',
  userId: req.user._id,
  courseId: course._id,
  courseTitle: course.title,
  timestamp: new Date()
});

🟡 Issue 4 — Admin enrollments endpoint queries wrong collection

GET /api/admin/users/:userId/enrollments likely queries legacy courses progress. Interactive enrollments live in UserCourseProgress.

Fix — query both:

const progress = await UserCourseProgress.find({ userId })
  .populate('courseId', 'title slug ceHours')
  .sort({ enrolledAt: -1 });
// merge with legacy Course enrollments if needed

🔵 Issue 5 — PostHog events not firing on enrollment / completion

In cready-viewer.js (or cready-viewer.html), after successful enroll POST and after attestation POST, add PostHog captures:

// On successful enroll:
if (window.posthog) posthog.capture('course_enrolled', { 
  courseId: course._id, slug: course.slug, title: course.title 
});

// On attestation complete:
if (window.posthog) posthog.capture('course_completed', { 
  courseId: course._id, ceHours: course.ceHours 
});
