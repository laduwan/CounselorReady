User Management

Finding Users

Go to Admin → Users to see all registered users. You can:

  • Search by name or email
  • Filter by subscription plan (Free, Starter, Professional, VIP)
  • Filter by status (Active, Trial, Canceled, Past Due)
  • Sort by newest, oldest, name, or last login

Editing User Accounts

Click "View Details" on any user to access management options:

Subscription Tab

  • • View current plan and billing dates
  • • Change subscription tier (bypasses Stripe)
  • • See Stripe customer ID

Admin Actions Tab

  • • Send password reset email
  • • Disable/enable account
  • • Login as user (impersonate)
  • • Delete user account

Managing Learner Enrollments

In the user's Courses tab, you can:

✓ Enroll in Course

Manually add user to any course

✓ Mark Complete

Admin-complete with optional note

↺ Reset Progress

Reset to 0% (keeps enrollment)

✕ Unenroll

Remove from course entirely

Course Management

Creating Courses

Go to Admin → Courses → Create New Course:

  1. Enter title, description, category, and CE hours
  2. Set access tier (Free, Starter, Professional, VIP)
  3. Add modules with lessons (video, text, quiz)
  4. Configure quiz questions and passing score
  5. Set to "Published" when ready

Importing External Courses

From Admin → Integrations → Imported Courses:

External Link

Link to course hosted elsewhere

SCORM Package

Upload SCORM 1.2 zip file

Starter Template

Quick course framework

Deleting Courses

From the Integrations page course table, click the trash icon. Warning: This will remove all enrollment data for that course.

Integrations

LTI (Learning Tools Interoperability)

Lets external LMS platforms embed your courses:

  1. Go to Integrations → LTI Connections
  2. Copy the Launch URL and Configuration XML
  3. Set up Consumer Key and Secret
  4. Share with the LMS administrator
  5. They configure their LMS to connect to your platform

xAPI / Tin Can API

Sends detailed learning data to your Learning Record Store (LRS):

Setup: Enter your LRS endpoint URL, username, and password in the xAPI tab. Test the connection before saving. Once configured, all learning activities (course starts, completions, quiz results) are automatically sent to your LRS.

CE Broker

Automatically reports CE completions to state boards (FL, GA):

  1. Get your Provider ID and API Key from CE Broker
  2. Enter credentials in the CE Broker tab
  3. Enable sandbox mode for testing first
  4. Switch to live mode when ready

Billing & Payments

Setting Up Stripe

Configure Stripe payments in your server environment:

STRIPE_SECRET_KEY=sk_live_xxxxx
STRIPE_WEBHOOK_SECRET=whsec_xxxxx
STRIPE_PRICE_STARTER=price_xxxxx    # $19.99/mo
STRIPE_PRICE_PROFESSIONAL=price_xxxxx  # $29.99/mo
STRIPE_PRICE_VIP=price_xxxxx        # $49.99/mo

Hardship & Compassion System

VIP Hardship Pauses

VIP members can request subscription pauses during hardships. Review in Admin → Hardship:

3-Tier Compassion System:
• 1st request: 30-day pause
• 2nd request: 14-day pause
• 3rd+ request: 7-day pause

You can approve, deny, or adjust the duration. Denials require a reason.
