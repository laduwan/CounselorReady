User Management

Finding Users

Go to Admin → Users to see all registered users. You can:

  • Search by name or email
  • Filter by subscription plan (Free, Starter, Professional, VIP)
  • Filter by status (Active, Trial, Canceled, Past Due)
  • Sort by newest, oldest, name, or last login

Editing User Accounts

Click "View Details" on any user to access management options:

Subscription Tab

  • • View current plan and billing dates
  • • Change subscription tier (bypasses Stripe)
  • • See Stripe customer ID

Admin Actions Tab

  • • Send password reset email
  • • Disable/enable account
  • • Login as user (impersonate)
  • • Delete user account

Managing Learner Enrollments

In the user's Courses tab, you can:

✓ Enroll in Course

Manually add user to any course

✓ Mark Complete

Admin-complete with optional note

↺ Reset Progress

Reset to 0% (keeps enrollment)

✕ Unenroll

Remove from course entirely

Course Management

🤖 Create with AI (Recommended)

The fastest way to create professional CE courses. Click the purple "🤖 Create with AI" button on the Courses page:

📋 Step-by-Step Process:

  1. 1
    Upload Your Content — Drag & drop a PDF or Word document, OR paste text directly into the content box
  2. 2
    Add Key Points (Optional) — Highlight specific concepts you want emphasized in the course
  3. 3
    Select Category & Hours — Choose Clinical or Ethics, and set CE hours (1-6)
  4. 4
    Choose Generation Options — Check "Generate quizzes" and/or "Generate learning objectives"
  5. 5
    Generate! — Click "Generate Course ⚡" and wait ~30-60 seconds
  6. 6
    Review & Edit — Preview the generated structure, make any adjustments
  7. 7
    Create Course ✓ — Save to your course catalog (starts as Draft)

✅ AI Generates:

  • • Course title & description
  • • Learning objectives
  • • Module structure with lessons
  • • Full lesson content
  • • Quiz questions with answers
  • • Proper CE categorization

💡 Best Practices:

  • • Use well-structured source documents
  • • Include research citations in your content
  • • Specify key points for emphasis
  • • Review all generated content before publishing
  • • Verify quiz answers for accuracy

Tip: After creating, click "Edit" on the course card to fine-tune content, add videos, adjust quiz questions, or modify the module structure before publishing.

Integrations

LTI (Learning Tools Interoperability)

Lets external LMS platforms embed your courses:

  1. Go to Integrations → LTI Connections
  2. Copy the Launch URL and Configuration XML
  3. Set up Consumer Key and Secret
  4. Share with the LMS administrator
  5. They configure their LMS to connect to your platform

xAPI / Tin Can API

Sends detailed learning data to your Learning Record Store (LRS):

Setup: Enter your LRS endpoint URL, username, and password in the xAPI tab. Test the connection before saving. Once configured, all learning activities (course starts, completions, quiz results) are automatically sent to your LRS.

Certificate Management

Automatic Certificate Generation

Certificates generate automatically when users complete a course:

  • User passes final quiz with required score
  • System generates PDF with user info, course details, CE hours
  • Certificate stored in user's account permanently
  • Unique certificate ID for verification

Reissuing Certificates

To reissue a certificate (e.g., name change):

  1. Go to Admin → Users
  2. Find the user and click "View Details"
  3. Go to the Certificates tab
  4. Click "Regenerate" on the specific certificate

Certificate Template

The certificate template is located in server/src/templates/. It includes:

• NBCC Provider Number (P207376)

• Digital signature

• CounselorReady branding

• QR code for verification

CE Broker Integration

Setting Up CE Broker

CE Broker automatically reports completions to state boards (FL, GA, SC, etc.):

  1. Contact CE Broker to get your Provider credentials
  2. Go to Admin → Integrations → CE Broker
  3. Enter your Provider ID and API Key
  4. Enable Sandbox mode for testing first
  5. Test with a real completion
  6. Switch to Live mode when ready

Troubleshooting CE Broker

Common Issues:

  • • Invalid credentials: Double-check API key and Provider ID
  • • User not found: User's license number may not match CE Broker records
  • • Course not approved: Ensure course has valid approval number
  • • Duplicate submission: Completion already reported

Manual Reporting

If automatic reporting fails, you can manually report:

  1. Go to user's certificate in Admin → Users
  2. Click "Report to CE Broker"
  3. Verify user's license info is correct
  4. Submit manually

SCORM Course Import

Importing SCORM Packages

Upload SCORM 1.2 packages from Admin → Integrations → Import Course:

  1. Click "Import SCORM Package"
  2. Upload your .zip file (must be valid SCORM 1.2)
  3. Set course title, category, and CE hours
  4. Configure access tier
  5. Click Import

SCORM Troubleshooting

Common Issues:

  • • "Invalid manifest": Package missing imsmanifest.xml
  • • "Unsupported version": Only SCORM 1.2 supported (not 2004)
  • • Content not loading: Check for missing resources in package
  • • Progress not tracking: Ensure SCO has proper API calls

User Impersonation

When to Use Impersonation

Login as a user to troubleshoot their specific issues:

  • Debug course playback issues they're experiencing
  • Verify their dashboard displays correctly
  • Check their credential/certificate access
  • Test subscription features for their tier

How to Impersonate

  1. Go to Admin → Users
  2. Find the user and click "View Details"
  3. Go to "Admin Actions" tab
  4. Click "Login as User"
  5. You'll be logged in as them in a new tab
  6. A banner shows you're impersonating
  7. Click "End Impersonation" when done

Safety Guidelines

  • • Never make purchases as the user
  • • Never change their password or email
  • • Always end impersonation when done
  • • All actions are logged for audit purposes

Understanding Analytics

Dashboard Metrics

Total Users

All registered accounts

Active Subscribers

Paying users (not canceled/paused)

Course Completions

Total courses finished this period

CE Hours Awarded

Sum of all completed course hours

Key Performance Indicators

  • Completion Rate: % of enrolled users who finish courses (aim for 70%+)
  • Quiz Pass Rate: % passing on first attempt (if <60%, review quiz difficulty)
  • Churn Rate: % of subscribers who cancel monthly (aim for <5%)
  • Average Session Time: How long users spend per visit

Hardship & Compassion System

VIP Hardship Pauses

VIP members can request subscription pauses during hardships. Review in Admin → Hardship:

3-Tier Compassion System:
• 1st request: 30-day pause
• 2nd request: 14-day pause
• 3rd+ request: 7-day pause

You can approve, deny, or adjust the duration. Denials require a reason.
